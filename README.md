# Nexxus - Site Institucional

Site profissional da Nexxus, empresa criativa especializada em criação de layouts para redes sociais, produção de vídeos e desenvolvimento de sites web.

## 🎯 Sobre o Projeto

Este é um site institucional moderno e responsivo que apresenta os serviços e o posicionamento da Nexxus. O site foi desenvolvido com foco em:

- **Profissionalismo**: Design limpo e elegante
- **Criatividade**: Elementos visuais inovadores
- **Inovação**: Tecnologias modernas e performance otimizada
- **Credibilidade**: Apresentação clara e estratégica dos serviços

## 🚀 Características

- ✅ Design responsivo (mobile-first)
- ✅ Animações suaves e interativas
- ✅ Navegação intuitiva
- ✅ Formulário de contato funcional
- ✅ Performance otimizada
- ✅ SEO friendly
- ✅ Acessibilidade

## 📋 Estrutura do Projeto

```
NEXXUS-SITE/
│
├── index.html      # Estrutura HTML principal
├── styles.css      # Estilos e design
├── script.js       # Interatividade e animações
└── README.md       # Documentação
```

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estrutura semântica
- **CSS3**: Design moderno com gradientes e animações
- **JavaScript**: Interatividade e efeitos
- **Google Fonts**: Tipografia (Inter e Playfair Display)

## 📱 Seções do Site

1. **Hero**: Apresentação principal com call-to-action
2. **Sobre**: Visão da empresa e valores
3. **Serviços**: 
   - Layouts para Redes Sociais
   - Produção de Vídeos
   - Desenvolvimento Web
4. **Público-alvo**: Empresas, empreendedores, marcas pessoais, igrejas e negócios locais
5. **Contato**: Formulário e informações de contato

## 🎨 Personalização

### Cores

As cores principais podem ser alteradas no arquivo `styles.css` através das variáveis CSS:

```css
:root {
    --primary-color: #6366f1;
    --primary-dark: #4f46e5;
    --secondary-color: #ec4899;
    /* ... */
}
```

### Conteúdo

- Edite o texto diretamente no arquivo `index.html`
- Atualize informações de contato na seção de contato
- Modifique os serviços conforme necessário

### Imagens

Para adicionar imagens:
1. Crie uma pasta `images/` no projeto
2. Adicione as imagens
3. Atualize os caminhos no HTML

## 📧 Formulário de Contato

O formulário de contato está configurado para exibir um alerta ao ser enviado. Para integrar com um backend:

1. Atualize a função de submit em `script.js`
2. Configure o endpoint da API
3. Adicione validação adicional se necessário

## 🌐 Como Usar

1. **Visualização Local**:
   - Abra o arquivo `index.html` diretamente no navegador
   - Ou use um servidor local (ex: Live Server no VS Code)

2. **Deploy**:
   - Faça upload dos arquivos para seu servidor web
   - Ou use serviços como Netlify, Vercel, GitHub Pages
